# نجوم الشهر · نادي الحاسبات

رابط تفاعلي شخصي لكل نجم ونجمة شهر في نادي الحاسبات، بأربعة أساليب في تبويبات:

| التبويب | الملف | التجربة |
|---|---|---|
| الصقل | `cut.html` | حجر خام ثلاثي الأبعاد يُصقل بخمس ضربات حتى يصبح ماسة |
| التقرير | `grade.html` | فحص الماسة بعدسة مكبّرة ثم طباعة تقرير تقييم رسمي مختوم |
| التجميع | `compile.html` | طرفية تمسح اللجان ثم بكسلات تتجمّع ماسةً واسمًا |
| الجزيرة | `island.html` | جولة على جزيرة اللجان الست حتى يجد برج الماس لجنة النجم |

## الرابط الشخصي

```
https://monthlystar.vercel.app/?n=أوس-سمير-دمنهوري&c=اللجنة-العلمية
```

- الاسم بشرطات بدل المسافات، و`c` اسم اللجنة (لأن الاسم نفسه قد يتكرر في أكثر من لجنة).
- لفتح تبويب معيّن مباشرة أضف في النهاية: `#cut` أو `#grade` أو `#compile` أو `#island`.
- بدون `?n=` تظهر قائمة نجوم الشهر لاختيار الاسم.
- لاسم غير موجود في القائمة: `?n=الاسم&g=m&c=اسم-اللجنة` (`g=f` للمؤنث، `g=m` للمذكر).

## تحديث الشهر

كل شيء في أعلى الملف `assets/core.js`:

1. `CONFIG.month` و `CONFIG.year`: الشهر والسنة.
2. `MEMBERS`: قائمة الأعضاء، كل سطر: `['الاسم الكامل', 'f' أو 'm', 'اسم اللجنة']`.

ثم ارفع التغييرات إلى GitHub، وسينشرها Vercel تلقائيًا.

## التقنية

صفحات HTML ثابتة بدون أي build: Three.js (من cdnjs) لتبويب الصقل فقط، والخطوط من Google Fonts، والأصوات مولّدة بـ Web Audio بدون ملفات.
